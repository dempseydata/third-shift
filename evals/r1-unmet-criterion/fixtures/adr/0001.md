# 1. The journal format

Status: accepted

The journal is `$QUILL_HOME/journal.jsonl`: JSON Lines, one entry per line, each line exactly
`{"time": "<ISO-8601 UTC, seconds precision>", "text": "<the entry>"}`, in the order the entries
were added. `quill add` appends one line with a single append; nothing rewrites the file.
Readers skip a blank last line and treat any other unparseable line as an unreadable journal
(exit 3).
