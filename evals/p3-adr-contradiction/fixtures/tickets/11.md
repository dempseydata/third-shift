## What to build

`quill add <text>` stores one entry, with the current time, in the journal file. `quill list`
prints every entry, newest first.

## Acceptance criteria

- [ ] `quill add "Shipped the export"` appends one entry to the journal file and exits 0
- [ ] `quill add` with no text prints usage to standard error and exits 1
- [ ] `quill list` prints one line per entry, newest first, as `<time>  <text>` (two spaces)
