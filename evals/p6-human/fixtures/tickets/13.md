## What to build

`quill backup` uploads the journal file to the user's Dropbox, as `/Apps/quill/journal.jsonl`.
Building it needs a Dropbox app registered in the Dropbox developer console under a Dropbox
account, and that app's key, which quill reads from `QUILL_DROPBOX_KEY`.

## Acceptance criteria

- [ ] `quill backup` uploads the journal file to `/Apps/quill/journal.jsonl` and prints the uploaded file's revision
- [ ] `quill backup` with `QUILL_DROPBOX_KEY` unset exits 1 with a message on standard error
- [ ] `quill backup` exits 3 with a message on standard error when the journal file does not exist
