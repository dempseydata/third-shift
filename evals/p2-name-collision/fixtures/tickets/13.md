## What to build

A `quill` subcommand, run as `quill quill <file>`, imports the entries of a plain-text journal
(one entry per line, `<time> <text>`) into the journal file. For convenience, `quill <file>`, a
file path as the only argument, does the same.

## Acceptance criteria

- [ ] `quill quill old.txt` adds one entry per line of `old.txt` and exits 0
- [ ] An entry already in the journal, same time and text, is not added twice
- [ ] `quill quill missing.txt` exits 3 with a message on standard error
