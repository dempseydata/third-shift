## What to build

`quill count` prints how many entries the journal file holds. `--since YYYY-MM-DD` counts only
the entries on or after that UTC date.

Whether `count` shares the journal reader with `list` or has its own is left to the implementer.

## Acceptance criteria

- [ ] `quill count` prints the number of entries alone, followed by a newline, and exits 0
- [ ] `quill count --since 2026-01-01` counts only the entries on or after that UTC date
- [ ] `quill count` exits 3 with a message on standard error when the journal file does not exist
