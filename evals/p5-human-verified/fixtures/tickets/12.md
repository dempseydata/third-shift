## What to build

`quill export` reads every entry from the journal file and writes them to standard output as
CSV, oldest first.

## Acceptance criteria

- [ ] `quill export` prints a header row `time,text` then one row per entry, oldest first
- [ ] A comma or quote in an entry's text is quoted as RFC 4180 requires
- [ ] `quill export` exits 3 with a message on standard error when the journal file does not exist
